# PID Controller Simulator ⚙️

Simulatore di un sistema di controllo PID (Proporzionale-Integrale-Derivativo) in Python.  
Progetto didattico pensato per introdurre le basi dei controlli automatici applicabili in robotica, automazione industriale e sistemi embedded.

## Funzionalità

- Classe PID completamente scritta in Python
- Simulazione di sistema con risposta nel tempo
- Visualizzazione grafica del comportamento

## Requisiti

- Python 3.x
- matplotlib (installabile con `pip install matplotlib`)

## Esecuzione

```bash
python pid_simulator.py
